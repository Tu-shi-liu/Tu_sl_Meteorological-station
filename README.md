#基于STM32F103C8T6的低功耗气象监测终端

#技术栈
>STM32F103C8T6、标准外设库、I²C/SPI协议、低功耗设计、Flash循环存储、按键状态机、OLED显示优化。

#项目概述
>以STM32F103C8T6为主控，集成AHT20/BMP280传感器、W25Q64 Flash、OLED显示屏，实现温湿度、气压的自动采集、循环存储、多页面显示及声光报警。支持持续监测与30分钟间隔低功耗待机模式，通过备份寄存器实现掉电记忆。
